# Third-party airline artwork

FlightWall v3.0.0 displays airline icon artwork from the open-source **Soaring Symbols** project when an icon exists in its catalog. The repository code is MIT-licensed. Airline names, logos, and trademarks remain the property of their respective owners and are used for identification and reference.

Upstream project: `soaring-symbols/soaring-symbols`

When an upstream icon is unavailable or cannot be loaded, FlightWall displays its built-in neutral fallback instead of inventing an airline logo.
